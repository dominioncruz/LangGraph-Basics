### LangGraph: Graphs and AI Agents

This repository documents my practical exploration of LangGraph, from understanding graph-based workflows to applying them in AI agent development. 
The projects use Google's Generative AI models and explore the building blocks of agentic systems.

#### Repository Structure
graphs/ — Graph Fundamentals

A collection of projects exploring graph concepts and how they are represented and executed using LangGraph. 
These projects establish the foundation for building more complex agent workflows.

#### agents/ — AI Agent Development

A collection of projects applying graph-based workflows to AI agents, covering foundational agent concepts and memory.

#### Technologies
- Python
- LangGraph
- Google's Generative AI models
#### Purpose

The goal of this repository is to build a practical understanding of graph-based orchestration and how it can support the development of AI agents, progressing from foundational concepts to more capable workflows.
